Windows · Three steps

From download to results

01

Extract the ZIP

Keep the executable and scripts in the same folder. The shaders are bundled, so there is nothing else to install.

02

Start the benchmark

Double-click Start Benchmark.cmd. Leave the window visible while all 21 shaders run; the full test takes about 1–2 minutes.

03

View your result

The runner saves benchmark-result.json next to the app and submits it here automatically. Browse the results page when it finishes.

What gets submitted

GPU model and driver, resolution, run time, shader IDs, FPS, and frame times. No account or name is required. Results are community submissions and are not independently verified.
